## Alpha 批（~3 周，全部 P0）

### WP-A1 · 真实 RAW 性能基准与优化【引擎】
- 用用户真实 RW2 样张（6K 全尺寸）建基准库；测：单张全尺寸解码、preview 1600px 降采样、缩略图首屏、5 万张库 query P95
- 产出：`docs/bench-1.1.0.md` 基线数据 + 优化（必要时：解码降采样直出、预览缓存策略）
- DoD：单张 6K RW2 预览 <1.5s（含落盘）；5 万张 query P95 <200ms

### WP-A2 · 健康校验后台化 + DB 自动备份【引擎】
- 校验/扫描全部走 JobManager（已有），补进度通知节流与取消响应
- `lumina.db` 每日自动备份，保留 7 份，启动时损坏自愈（备份恢复）
- DoD：大库校验期间 UI 全程可操作；删 db 后重启能自动恢复

### WP-B1 · 浅色主题修复【UI】
- 根因排查：smoke 实测 `light=#0c0d10`（与深色同值）、`viewerBg=none` —— 主题变量注入链路断
- 修完后：设计稿 09 帧浅色规范逐项比对；查看器恒色 `#08090B` 不翻转
- DoD：smoke theme 行 `changed=true` 且浅色值与设计令牌一致；两套主题截图入 `docs/ui-1.1/`

### WP-B2 · UI 与 13 帧设计稿逐帧对齐【UI】
- 逐帧走查 `lumina-design-deliverables/*.png` vs 实现，出差异清单（间距/层级/状态/字号）
- 按设计令牌修正；清理存量硬编码色值（照片观察区 `#08090B` 除外）
- DoD：差异清单清零；`grep -rn "#[0-9a-fA-F]\{6\}" app/src` 白名单外为 0

### WP-B3 · 空态/加载/错误三态统一 + 冷启动进度【UI】
- 每页三态组件统一（无数据/加载中/失败重试）；所有 catch 必须有 UI 呈现（零静默红线）
- 冷启动三段进度（引擎握手→库加载→缩略图就绪）
- DoD：人为制造引擎不启动/文件缺失/空库三种场景，页面均有明确提示与恢复入口

## Beta 批（~4 周）

### WP-A3 · HSL 8 色带引擎参数链【引擎】
- `edit.params` 的 hsl 8 色带（hue/sat/lum × 8）在 XMP 往返、develop 会话、导出管线全链路打通
- DoD：设置色带 → endSession → sidecar crs:HSL 字段正确 → 重新打开读回一致

### WP-A4 · 地图离线瓦片 + GPX 导入【引擎】
- `map.getTile {z,x,y}`：本地 MBTiles/瓦片包目录优先，未命中回退在线（可配置开关）
- `map.importGpx {path}`：解析轨迹点 → 返回可批量写 GPS 的点位集；`map.applyGpxPoints` 批量写入
- DoD：断网环境地图可浏览已缓存区域；GPX 导入 → 择点 → 写 GPS → sidecar 验证

### WP-A5 · 健康任务化收尾 + NAS 差异报告导出【引擎】
- 双备份差异报告导出 CSV/JSON
- DoD：制造差异 → 导出报告字段完整

### WP-B4 · 真 HSL 8 色带 GPU 实装【UI】（依赖 A3）
- shader 实装 8 色带（hue/sat/lum 三分量），替换曲线 LUT 近似
- DoD：色带滑块实时预览，与导出结果目视一致；shader 编译零告警

### WP-B5 · 笔刷逐笔 SDF 渲染【UI】
- 逐笔画（strokes 全量）SDF 融合，替换质心近似；流量/密度真实叠加
- DoD：多笔交叉笔迹边界与蒙版红色覆盖层一致

### WP-B6 · CPU 软渲染保底【UI】
- WebGL 不可用时 2D 像素管线：曝光/对比/高光阴影/白平衡/饱和近似生效（性能：1600px 预览 <100ms/帧）
- DoD：`--disable-webgl` 强制关闭后修图台参数仍可见变化

### WP-B7 · 修图台工作流对齐 LR【UI】
- 面板折叠记忆、复制/粘贴设置、上/下一张循环（Ctrl+' / Shift+Ctrl+'）、`?` 快捷键速查浮层、完整快捷键表入文档
- DoD：快捷键表内全部按键在 UI 生效

### WP-B8 · 交付与画廊增强【UI】（依赖 A5 部分接口）
- 水印编辑器（文字/位置/透明度所见即所得）；画廊链接有效期/下载次数/客户留言标记 UI
- DoD：水印导出产物含水印；画廊设置生效
