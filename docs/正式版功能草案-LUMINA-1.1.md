# LUMINA 正式版（v1.1.0）功能草案书

> 状态：**草案 v0.1 —— 待用户评审**　｜　日期：2026-10-22　｜　基线：v1.0.0 已交付版
> 定位：v1.0.0 是"功能闭环的内测版"；v1.1.0 是面向正式对外发布打磨的**正式版**——重点是稳、准、顺手感，而不是堆新功能。

---

## 一、正式版目标（一句话）

**让摄影师敢把它当日常主力工具**：真实大库不卡、每个面板都经得起每天 8 小时使用、界面与设计稿 Glass Noir Grain v2 完全对齐、任何失败都有明确提示（零静默）。

## 三、功能草案（按模块）

### 3.1 素材库（稳定优先，小步增强）
- **大库性能基准**：5 万张级真实库滚动浏览 ≥60fps、搜索 <200ms（P95）
- 目录树收藏夹（ pinned roots ）
- 重名/重复照片智能检测入口（已有 RAW+JPG 配对基础上扩展感知哈希）
- 评级/色标在胶片条上直接可改（现在需进详情）

### 3.2 修图台（正式版核心投入）
- **真 HSL 8 色带**（P5）：色相/饱和/明亮三分量 × 8 色，GPU 实装
- **笔刷精确渲染**（P4）：逐笔 SDF + 流量/密度真实叠加
- 调整栈与 LR 对齐：复制粘贴设置、上/下一张快捷循环（Ctrl+' / Shift+Ctrl+'）
- 参数面板记忆折叠状态
- **CPU 软渲染保底**：WebGL 完全不可用的机器上参数仍可近似生效（当前 2D 降级只显原图）

### 3.3 地图
- 离线瓦片底图（ photographer 外拍无网场景，1.0 依赖在线瓦片 ）
- 按日期回放轨迹动画（拍摄动线复盘）
- GPX 导入直接写回 GPS（现在是手动选点）

### 3.4 延时工作台
- Holy Grail 日转夜关键帧曲线编辑器 UI 化（引擎已有关键帧模型）
- 去闪预览对比（before/after 同屏）
- 渲染队列完成后的自动归档到作品集

### 3.5 风光专项
- 全景拼接（v1.0 路线图已列入 1.1）：自动 spherical 投影 + 接缝融合
- 景深堆栈（对齐 + 堆叠 + 残影剔除）
- AI 降噪评估版：1.0 的 NLM 经典降噪保留为"兼容模式"，接入可插拔 AI 推理后端（本地 ONNX，可选下载）

### 3.6 导出与交付
- 导出预设与"交付清单"绑定（客户 → 规格 → 一键全套）
- 水印编辑器（文字 logo 位置/透明度/缩放所见即所得）
- 画廊：链接有效期、下载次数限制、客户留言标记

### 3.7 存储健康
- 校验任务后台化 + 完成通知（当前大库校验阻塞感明显）
- NAS 双备份差异报告导出

## 四、UI/UX 调整方向（用户点名要调）

1. **与 13 帧设计稿逐帧对齐审查**：1.0 实现与 Ardot 设计稿存在间距/层级/状态细节偏差，正式版逐帧走查出差异清单，按令牌修正（禁止硬编码色值的存量清理）
2. **修图台布局弹性**：左右面板可折叠 + 记忆；双显示器（查看器独立窗口）评估
3. **快捷键体系**：整理完整快捷键表 + 面板 `?` 速查浮层（摄影师键盘流是核心体验）
4. **浅色主题交付**（P2 修复后）：打印/日光场景可用，查看器恒色规则不变
5. **空态/错误态统一**：每个页面补齐"无数据/加载中/失败重试"三态（修图黑屏事件的最大教训）
6. **启动体验**：冷启动进度可见（引擎握手→库加载→缩略图就绪三段进度），不再"点了没反应"

## 五、工程质量与发布门槛

| 门槛 | 标准 |
|---|---|
| 稳定性 | 连续 8 小时混合操作无崩溃；强杀后重启自动恢复会话 |
| 性能 | 5 万张库：冷启动 <15s、网格滚动 60fps、search <200ms、单张 RAW 预览 <1.5s |
| 数据安全 | 原片零改写回归测试 100%；DB 每日自动备份（保留 7 份）；升级前强制校验 |
| 兼容 | Win10 21H2+ / Win11；Intel 核显与无 GPU 机器（软渲染）全功能可用 |
| 零静默 | 所有 IO/解码失败必须有 UI 呈现（红线条目 + 汇总），不允许 console-only |
