## 1. 产品目标

### 1.1 一句话目标

> **M2 做完后，用户在蒙版里做的每一次局部调整、在几何与镜头里做的每一次校正、以及昨天调过的 20 步，都能在导出结果里和重启之后原样成立。**

### 1.2 用户可感知的六条（对照差距收口，**不承诺「像 LR」**）

| # | 可感知变化 | 收口的差距项（R5 §3） |
|---|---|---|
| 1 | 渐变 / 径向 / 画笔 / 范围蒙版**真的改变像素**，且**导出与预览一致**（当前导出完全不应用蒙版） | 局部调整与蒙版 🟡→✅ |
| 2 | 蒙版数量**不再有 6 个硬上限** | 同上 |
| 3 | 风光三件套可用：压暗天空、提亮前景、按颜色选树叶 | 同上（存量 83.8% 含蒙版） |
| 4 | 建筑直线可校正：畸变 + 透视 + 裁剪**一次重采样**不软化 | 变换/几何 ⬜→🟡、镜头校正 ⬜→🟡 |
| 5 | 关掉软件重开，**撤销链还在**（跨会话 undo/redo） | 历史/快照/虚拟副本 🟡→✅ |
| 6 | 库里能按「有蒙版 / 有调整」筛选，**删缓存不丢参数**（sidecar 仍唯一真相源） | 目录库 🟡→✅（保 R1 不锁库） |

### 1.3 明确不做什么（边界，写清以免扯皮）

| 不做项 | 理由 |
|---|---|
| **`.lrcat` 导入** | 全仓无任何 lrcat 代码；本轮口径已由用户裁定走「范围冻结」口径，不在 M2 |
| 修复画笔 / 图章 / 文字 / 选区 / 像素图层 | 属 PS 精修档（265 人日档），v1.3+ |
| **搬运 Adobe 的 LCP / DCP 资产**（不得内置、不得反编译、不得分发） | 合规红线（KICKOFF §4.1-7「参数化，不内置 LCP」；R1 报告红线复述）。**注意与 Q3 定案的区别**：Q3 允许内置「自建或许可清晰的第三方镜头数据库」（如 lensfun DB，CC-BY-SA），**不等于**允许搬运 Adobe 资产 |
| legacy 渲染双轨 / 旧引擎旁路 | D1 与 PRD §9-Q2：不保留旧渲染引擎 |
| 新增第 9 个右栏面板 | **D2 硬约束：8 类节点 = 8 个右栏面板（1:1）**，蒙版必须挂在宿主节点内 |
| 追 Adobe Standard / 「像 LR / 等同 ACR」表述 | **D3 硬约束**，验收只认 ΔE 数值 |
| 动目录库 / XMP / IPC 三层资产 | R5 §8.1：这是资产不是包袱（R1 不锁库） |
| AI 蒙版（主体/天空/背景自动识别） | 协议已声明 `aiSky/aiSubject/aiBackground`，本版**置灰 + 显式告知**，不静默 |

## 6. 验收口径（机器可判定，全部进 CI）

### 6.1 表述纪律（D3 硬约束）

- 全文、UI 文案、发布说明**禁止**出现「像 LR / 等同 ACR / 复刻 Adobe Standard / 追平 Camera Raw」。
- 色彩与蒙版只允许写**可测数值 + 样本量**（如「中位 ΔE00 = 2.7，n = 32 对」）。
- 违反即视为该需求**未验收**（与 PRD §6.3「肉眼看着接近 = 未验收」同口径）。

### 6.2 蒙版类（P0-01~03）

| # | 断言 | 判据 |
|---|---|---|
| A1 | 单蒙版正确性（4 类 × 3 组参数） | 与「逐蒙版 CPU 浮点参考实现」比对 `mean\|Δ\| ≤ 2/255`，`max ≤ 6/255`（GPU 与引擎双通道各自成立） |
| A2 | 区外纯净 / 区内有效 | 相对「无蒙版基线」：区外 `max\|Δ\| ≤ 1 LSB`；区内曝光 ±1EV 时均值变化 ≥ 8/255 |
| A3 | **导出 = 预览（含蒙版）** | `masks[]` 从「parity 排除」改为**纳入**：`mean\|Δ\| < 0.5`、`max ≤ 3 LSB`（当前 M1 明确排除，这是本轮必须补的格） |
| A4 | 槽位真实生效 | 20 蒙版逐个关闭，每次均产生 ≥ 阈值差异（证明第 7–20 槽参与求值，而非被截断） |
| A5 | 无回落分支 | 静态检查：`luminanceRange/colorRange` 类型不存在「落到画笔分支」的代码路径（M1 的静默失效不得复现） |
| A6 | 往返一致 | 蒙版 JSON 序列化→反序列化→再序列化**字节稳定**；旧 sidecar 抽 50 张，`mask` 字段逐字段等值 |
| A7 | 方向正确性（分区口径） | 亮度范围：范围外高光块与暗块差异 `≤ 1 LSB`；范围内 Δ ≥ 阈值。**判定必须用分区统计，禁止用整幅均值**（K2/K3 教训） |

### 6.6 K2/K3 口径收口（P0-08，**M2 的前置闸门**）

| 项 | 规定 |
|---|---|
| 现状 | M1 §五 K2/K3 定性为「**断言口径局限，非缺陷**」：8bit 整幅均值对**保均值算子**（clarity/texture/sharpness/colorNR）、**零均值噪声**（grain）、**小面积效应**（vibrance/saturation/blueSat）、**设计值低于阈值**（temperature/tint）不灵敏。**本轮不得写成「已解决」——它至今未解决。** |
| 本轮要求 | 新增**分区统计器**：分区表与阈值**由架构师定**（建议形态：5×5 网格 + 亮度四分位 + 局部方差 + 色度 a\*b\*/C + 边缘梯度能量）。**PRD 只锁两条硬要求（Q5 定案，逐字执行）**：① **必须能区分「保均值算子」与「无操作」**；② **阈值只许收紧不许放宽** |
| 出口 | K2 点名的 10 个叶 + K3 的 dehaze，在新口径下**全部可判定「生效且方向正确」**；旧 8bit 整幅均值口径保留为回归项（不删除，但不再作为唯一判据） |
| 为什么必须现在做 | 蒙版验收的 A2/A7 本质是「区内 vs 区外」的**局部统计**；沿用整幅均值口径时，小面积蒙版效应会被稀释到阈值以下 → **蒙版类验收无法成立**（K1 的「一致地错」风险重演） |
| 纪律 | 这是**更换口径**，不是**放宽门槛**：新判据写死进 CI，阈值只许收紧（与 PRD §9-Q5「只许收紧不许放宽」同源） |
