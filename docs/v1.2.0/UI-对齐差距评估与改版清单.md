# UI 对齐差距评估与改版清单（M2b 候选）

> 文档版本：UI-GAP-1.0 · 日期：2026-10-26 · 产出人：许清楚（PM） · 任务 #6
> 起因：用户反馈「**界面像 PS/LR 靠齐不明显**」。
> 评估基准：`docs/v1.2.0/R6-UI重构设计方向.md`（v1 布局 + v2 Soft Depth + v3 面板归属校正）与 `docs/v1.2.0/R7-macOS视觉方向.md`（材质收束）。
> 现状勘察（2026-10-26，只读）：`app/src/App.tsx`、`components/shell.tsx`、`modules/develop/{DevelopPage.tsx, panels/*.tsx}`。
> **定位关联（2026-10-26 重定位）**：本清单服务 R6 判据 5「打开即知这是修图软件」——通用专业工作流的**信息架构**向 PS/LR 对齐；风光特色不进布局，只保留特色徽标入口（已落地）。PS/LR 仅作**内部评估参照**，对外文案不得出现「像 LR / 等同 PS」（D3 + 重定位禁语）。
> **本清单只做评估与排期建议，不改代码**；实现排入 **M2b 之后**。

---

## 一、结论摘要

1. **骨架已对齐，壳上细节没对齐**：LR 式模块拾取器、右栏 8 面板 = NodeGraph 1:1（93 叶归属逐组标注）、左栏导航器/预设/历史、R7 macOS 材质令牌**均已落地**——布局层的「靠齐」其实已完成大半。
2. **用户感知「不像」的来源，集中在 5 个「PS 标志性壳元素」缺失**：真菜单栏、文档标签页、选项栏、工具轨、状态栏。这五件在 R6 v2-B（补 PS 结构细节）里全部点名，但截至勘察日**一项都未实现**。缺的不是配色，是**结构**——与用户「不是配色微调」的判断一致。
3. 改版清单按「感知强度 ÷ 成本」排三批：**M2b-1（菜单栏 + 状态栏 + 快捷键补齐）感知最强、成本最低**；M2b-2（dock 标签组 + 快照/图层常驻化）；M2b-3（文档 Tab + 工具轨 + 选项栏，与精修工作区联动）。

## 四、M2b 排期建议（三批，可穿插在 M2 工程任务之间）

| 批次 | 内容 | 合计量级 | 理由 |
|---|---|---|---|
| **M2b-1 壳补齐（感知最强）** | G1 真菜单栏（接线现有功能，不新增能力）+ G2 状态栏 + G3 三键补齐 + G11 hover 形态 | **~4 人日** | 三项都是纯壳工作，不碰参数模型与引擎；「点菜单有真响应」+「底部有专业状态栏」是用户 30 秒内就能感知到的变化 |
| **M2b-2 面板心智对齐** | G4 快照/图层从弹窗改左栏常驻（按 LR 顺序：导航器→预设→快照→历史）+ G5 dock 标签组 + G6 画布外框 | ~5 人日 | 把「藏在弹窗里的专业功能」变成「常驻可见」，专业密度可感知；与 T2.8 history 落盘的面板行为联动 |
| **M2b-3 精修结构**（可与 M3 PSD 联动） | G7 选项栏 + G8 工具轨 + G9 文档 Tab | ~8–10 人日 | 依赖蒙版画布工具形态（T2.2）与多文档语义决策（D1）；建议随 M3 PSD 出口一起做，届时「文档」概念才有实体 |

> 排期纪律：M2b 批次全部为**纯 UI 壳工作，不进 M2 出口条件**（M2 出口仍由 M2-01~11 的引擎/数据验收口径把守）；不得为做壳挤占 P0-01~12 工期。

## 五、需要用户/主理人拍板的 3 项（不拍板不排期）

| # | 问题 | 建议 |
|---|---|---|
| D1 | **文档标签页（G9）的语义**：产品是「库 + 单图」模型，PS 的多文档 Tab 在 LUMINA 指什么？ | 建议：Tab = **多开照片对比/接力修图**（图库选中多张 → Tab 切换），不是 PS 的画布多文档；若用户想要的是「多文档工作区」，建议推迟到 v1.3（数据模型成本高） |
| D2 | **快速/专业双模式去留（G10）**：保留双模式还是收敛为单一右栏？ | 建议：**保留快速模式但降格**——专业模式为默认（对齐 LR 心智），快速模式改名「精简」并作为可关闭的简化视图，不再平级；彻底删除留待用户反馈 |
| D3 | **菜单栏形态**：自绘菜单（跨平台一致，成本 M）还是 Electron 原生菜单（Windows 原生感，成本低）？ | 建议：**自绘**（R6 v2-B1 的 hover 整项填色是 PS 特征，原生菜单做不到），但菜单项只接线**已存在**的功能，不新增承诺 |

## 六、验收口径（M2b 批次复用时引用）

- M2b-1：菜单栏每项可点且落到真实功能（0 个「即将开放」toast 残留，静态检查 + 用例）；状态栏六字段实时正确（缩放/色彩空间/位深/尺寸/大小/节点数，逐字段断言）；Tab/F/双击归零进键帽表且有行为用例。
- M2b-2：快照/图层常驻可见（不再以 Dialog 为唯一入口）；dock 标签组切换不丢面板状态；左栏顺序 = 导航器→预设→快照→历史（截图评审）。
- M2b-3：随 M3 联动验收（PSD 文档 Tab、工具轨与蒙版画笔联调），本文不预设。
- 通用：观察区 `#08090B` 不被任何新元素覆盖（R5 红线）；无新增硬编码色（走令牌，R7 §5）；对外文案零「像 LR / 等同 PS / 风光专用」。
