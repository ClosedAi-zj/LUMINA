# R6 · v1.2.0 UI 重构设计方向（冻结稿）

> 日期：2026-10-24 · 状态：方向冻结，待用户视觉评审 · 前置：`v1.2.0-启动-对标路线与范围冻结.md`
> 一句话：**骨架学 PS + 组织学 LR + 皮肤是 LUMINA。**

---

## 1. 设计判据（评审时只看这五条）

1. **老手零学习成本**：PS/LR 用户的肌肉记忆（面板位置、快捷键、参数顺序）不能被打断。
2. **照片永远是主角**：任何界面元素不得与照片争夺注意力；观察区恒定 `#08090B`。
3. **参数可数**：右侧每个面板组 = NodeGraph 一个节点类型，签收即对齐。
4. **不装饰**：没有渐变、没有投影、没有圆角气球。层次靠 1px 线与底色差。
5. **一屏可判**：打开即知"这是修图软件"，不是"又一个图片管理器"。

---

## 2. 统一外壳：PS 的骨架 + LR 的模块

```
┌──────────────────────────────────────────────────────────────────────┐
│ 菜单栏 32px  File Edit Image Layer Select Filter View Window Help    │  ← 学 PS：全菜单
│              [库] [修图] [精修] [输出]        ⌕ 搜索    [导出]  [⚙]  │  ← 学 LR：模块切换
├───────┬──────────────────────────────────────────┬───────────────────┤
│ 左栏  │              照片观察区                   │      右栏         │
│       │              #08090B 恒定                │  参数面板坞       │
│       │                                          │  长卷轴 + 折叠     │
├───────┴──────────────────────────────────────────┴───────────────────┤
│ 胶片条 96px（库/修图/精修都有，输出没有）                            │  ← 学 LR
└──────────────────────────────────────────────────────────────────────┘
```

- 菜单栏：34px 高，13px 字，条目间距 18px，hover 底色 `--hover`。
- 工作区切换不是 Tab，而是**四个并列文字按钮**（LR 的模块选择器形态），当前项文字变 `--accent`，下方 2px 金色短线。
- 搜索框在右侧，占 220px，`⌘K` 唤起。

## 3. 四个工作区

### 3.1 库（Library）——学 LR Library

| 区 | 宽度 | 内容 |
|---|---|---|
| 左 | 260 | 目录树（全部照片/上次导入/文件夹/收藏夹/智能收藏）+ 存储健康入口 |
| 中 | 自适应 | 网格视图，缩略图 3:2，间距 8px，单元格信息条（文件名 + 星级 + 色标） |
| 右 | 300 | 直方图 + 快速调整（曝光/对比/高光/阴影）+ 元数据 + 关键字 |
| 底 | 无胶片条 | 底部只留状态条：`18,192 张 · 512GB · 缺失 0` |

### 3.2 修图（Develop）——学 LR Develop，这是主战场

| 区 | 宽度 | 内容 |
|---|---|---|
| 左 | 240 | 导航器 + 预设 + 快照 + 历史（LR 顺序） |
| 中 | 自适应 | 单张查看器，恒定 `#08090B`；四角信息（文件名/焦距/快门/ISO）极淡 10px |
| 右 | 320 | 长卷轴：直方图 → 基础 → 曲线 → 色彩（HSL+分级）→ 细节 → 镜头 → 几何 → 效果 → 校准 |
| 底 | 96 | 胶片条，横向滚动，当前项 2px 金边 |

**面板组 = NodeGraph 节点类型（1:1）**：

| 面板组 | 节点类型 | 参数叶 |
|---|---|---|
| 基础 | `basic` | 曝光/对比/高光/阴影/白/黑/色温/色调/自然饱和/饱和/纹理/清晰度/去雾 |
| 曲线 | `curve` | 复合点 / 分通道 / 参数曲线 |
| 色彩 | `color` | HSL 8 带 / 颜色分级 / 黑白混合 |
| 细节 | `detail` | 锐化 4 项 / 降噪 4 项 |
| 镜头 | `lens` | 配置文件 / 色差 / 暗角 / 畸变 |
| 几何 | `geometry` | 裁剪 / 拉直 / 透视 / 比例 |
| 效果 | `effects` | 暗角 / 颗粒 / 分离色调 |
| 校准 | `calibration` | 阴影/红/绿/蓝 原色 各 2 项 |

> 这条对齐是本次重构最关键的约定：**面板数 = 节点数 = 8**。UI 不多不少。

### 3.3 精修（Retouch）——学 PS

| 区 | 尺寸 | 内容 |
|---|---|---|
| 选项栏 | 36 | 当前工具的选项（PS 的 options bar） |
| 工具轨 | 48 | 单列线性图标：移动/裁剪/画笔/修复/图章/橡皮/渐变/文字/钢笔/吸管/缩放/抓手 |
| 画布 | 自适应 | 可多文档 Tab |
| 右 | 340 | 图层栈 / 通道 / 路径 / 历史 / 属性 五个可折叠组 |
| 底 | 24 | 状态栏：缩放比例 / 色彩空间 / 位深 / 文档尺寸 |

> 注意：这里的"图层"是**参数图层**（NodeGraph 节点的可视化），不是 PS 的像素图层树。像素层只在 PSD 导出时物化。

### 3.4 输出（Output）——三栏

导出预设 | 大图预览 + 水印预览 | 队列与历史

## 4. 借什么，不借什么

**必须借（否则老手不适）**
- PS：菜单栏全量层级、选项栏、工具轨、面板折叠、Tab 隐藏面板、可配置快捷键
- LR：模块切换、右侧长卷轴参数面板、胶片条、`\` 前后对比、`Tab` 隐藏侧栏、参数双击归零
- 两者共同：面板标题 11px 全大写 + 0.08em 字距；参数行 22px 高；滑块轨道 3px

**坚决不借**
- PS 的贴图质感、渐变工具栏、浮动小面板群（现代版已收敛）
- LR 的蓝色系品牌色（我们用金色）、圆角卡片
- 任何"技能发现型"引导气泡

---

## 5. LUMINA 自有风格（6 条硬规则）

1. **线而非影**：层次只用 1px `--border` 与底色差；浅色主题尤其禁止投影。
2. **金色只标状态**：`--accent #E8C268` 仅用于当前工作区、当前工具、激活滑块、焦点；不做装饰填充。
3. **观察区恒定**：`#08090B`，深浅主题都不变（照片显色一致性优先于主题统一）。
4. **数字等宽**：所有参数值、尺寸、计数用 JetBrains Mono + `tabular-nums`。
5. **圆角 ≤ 2px**：`radiusSm 2 / radiusMd 4`，一律不用大圆角。
6. **颗粒只给边界**：查看器四周可有极轻的噪点质感（模拟相纸边缘），强度 ≤ 3%，不得进入照片区。

| 操作 | 键 | 来源 |

## 7. 双主题

- 深色（默认）：画布 `#0C0D10` / 面板 `#14161A` / 卡片 `#1D2025` / 悬停 `#22252B` / 线 `#2A2D33` / 主文 `#E8E6E1` / 次文 `#9A968E` / 弱文 `#6B6862`
- 浅色（相纸）：画布 `#F4F3F0` / 面板 `#FFFFFF` / 卡片 `#FAF9F6` / 线 `#E4E2DC` / 主文 `#1A1917` / 次文 `#6B6862` / 强调 `#B98A2E`

# 附：v2 修订（2026-10-24 23:55，用户视觉评审后）

> 用户反馈原文要点：① 布局与 PS 有几分相似但**可以更相似**（参考 photocraft / lightcraft 的界面截图）；② 都是比较方形化的框框，希望改成**现在流行的弧形 + 一点点立体感**。
> 结论：§5 的第 1 条（线而非影）与第 5 条（圆角 ≤2px）**作废**，替换为下面的「Soft Depth 柔和纵深」语言。§2–§4 的布局主张不变，另补 PS 结构细节。

## A. 设计语言 v2：Soft Depth（柔和纵深）

一句话：**保留专业软件的密度，把硬边框换成圆角卡片 + 低对比柔影；层次靠"浮起来"而不是"画条线"。**

### A1. 圆角体系（替换原 ≤2px）
```
--r-xs  4px   输入框内元素、小徽标
--r-sm  6px   工具按钮、小标签
--r-md  8px   参数行、缩略图、下拉、按钮
--r-lg  12px  面板、卡片、dock 分组
--r-xl  16px  照片容器、空状态
--r-pill 999px 搜索框、chips、主按钮（可选）
```

### A2. 纵深三层（同层不加影，跨层才加影）
| 层 | 用途 | 深色 | 浅色 |
|---|---|---|---|
| L0 底 | 画布、查看器外框 | 无 | 无 |
| L1 面 | 左右面板、dock 分组 | `0 1px 2px rgba(0,0,0,.55)` | `0 1px 2px rgba(24,20,12,.06)` |
| L2 浮 | 弹出菜单、下拉、模态、拖动中的面板 | `0 8px 24px rgba(0,0,0,.45), 0 1px 3px rgba(0,0,0,.5)` | `0 10px 30px rgba(24,20,12,.10), 0 1px 2px rgba(24,20,12,.06)` |

**硬约束**：阴影不得越过照片观察区边界；照片内部永远不带任何投影或模糊。

### A3. 顶栏与浮动层用轻玻璃（只用两处）
```
深色：background rgba(21,23,28,.72) + backdrop-filter blur(18px) saturate(160%)
浅色：background rgba(255,255,255,.75) + backdrop-filter blur(18px) saturate(140%)
```
顶栏、模态、下拉三处可用；**面板本体不用玻璃**（避免大面积模糊伤照片判断）。

### A4. 控件现代化
- 滑块：轨道 4px 圆头；滑块球 12px，2px 面板色描边 + L1 柔影；hover 球放大到 14px
- 参数行：高 24px，圆角 8px，hover 底色 `--hover`；双击归零保持不变
- 选中态：`accent 12% 底 + accent 40% 边框 + 圆角 8px`（不再用纯色块）
- 焦点环：`0 0 0 2px accent/25%`（键盘可见）
- 缩略图：圆角 8px，hover 放大 1.02 + L2 影，过渡 120ms
- 主按钮：accent 实色 + `0 2px 10px accent/25%`，圆角 8px
- 卡片间距：面板之间 8px 间隙（不再是通栏贴边），dock 整体 12px 内边距

### A5. 动效（克制）
- 过渡统一 120ms / cubic-bezier(.2,.8,.2,1)
- hover 上浮 1px；按下滑块/按钮给 1px 内阴影
- 面板折叠 160ms 高度过渡；**禁止**弹跳、缩放超过 1.04

## B. 补 PS 结构细节（提高"像 PS"的忠实度）

1. **菜单栏**：9 项齐全 + 右侧控件；菜单项 hover 整项填色（PS 特征）
2. **文档标签页**：画布上方一排标签（`徽州-晨雾.RW2 ×`），当前标签与画布同底色，非当前标签更暗
3. **选项栏**：精修屏保持 36px；修图屏可并行显示"当前工具 + 同步/复位"两个按钮
4. **工具轨**：20 个图标分 4 组，组间 1px 分隔线；底部放前景/背景色块（PS 标志性元素）
5. **右侧 dock 用标签组**：`属性 | 调整`、`图层 | 通道 | 路径 | 历史`——同一 dock 内切 tab，而不是竖着堆 5 个组
6. **状态栏**：`缩放 66.7% | RGB/16 | 6000 × 4000 px | 6.2 MB | 4 个节点`
7. **画布外框**：深灰 `#17191D`（PS 的画布外围），照片带 16px 圆角

## C. 不变的底线
- 照片观察区恒定 `#08090B`，两主题都如此
- 金色仍只用于激活/焦点/主按钮，占比目标 ≤2%
- 数字等宽、面板标题不做全大写（v2 改为 12px 半粗，更现代）
- 面板组 = NodeGraph 节点类型，8 组不变

# 附：v3 面板归属校正（2026-10-25 00:40，对齐架构设计 D2）

架构文档 `docs/架构设计-LUMINA-v1.2.0.md` 的决策 D2 指出：R6 §3.2 表里把「分离色调」放在**效果**组，但它在数据上就是 `colorGrade` 节点的 8 个 `SplitToning*/ColorGrade*` 参数叶。两处都渲染 = 双控件 = 双真相源，违背「面板组 = 节点」的单源原则。

**修正（覆盖 R6 §3.2 的对应行）**：

| 面板组 | 节点 | 包含参数叶 | 数量 |
|---|---|---|---|
| 色彩 | `color` | HSL 24 + 颜色分级 8（**含原"分离色调"的 8 叶**） | 32 |
| 效果 | `effects` | 暗角 3 + 颗粒 3 | 6 |

- 面板总数仍为 8（基础/曲线/色彩/细节/镜头/几何/效果/校准），参数总数仍为 93。
- 设计稿 `mockup-v2.html` 的「效果」组里那三项分离色调，实现时**移入「色彩」组**；阶段 3 重做右栏面板时一并处理，本阶段（外壳）不动。
- 同时执行此前已定的取舍：右栏卡片间隙 **8px → 6px**，让「曲线」默认展开可见。
