# R7 · v1.2.0 macOS 视觉方向（在 R6 Soft Depth 基础上收束）

> 2026-10-25 用户指示：界面向 macOS 靠拢。本文档是 R6 v2/v3 的**增量修订**：布局与面板归属（R6 v1/v3）不变，视觉语言从「Soft Depth」收束为「macOS frosted」。

## 1. 一句话

**PS/LR 的信息架构 + macOS 的材质与气质。** 不抄 macOS 布局，抄它的三层质感：通透侧栏、悬浮式工具条、大圆角柔和阴影。

## 2. 材质三层（替代 R6 的 L1/L2 两层）

| 层 | 用途 | 材质 |
|---|---|---|
| M0 实面板 | 右栏调整面板、底部胶片条 | 实色卡片色 + hairline 边框（不透明，保可读性） |
| M1 通透侧栏 | 左侧轨道栏（LeftRail）、二级导航 | 半透明 `glass` 令牌 + `backdrop-filter: blur(20px) saturate(1.4)` |
| M2 悬浮玻璃 | 顶栏、下拉菜单、模态、图库筛选浮层 | 同 M1 玻璃，加 shadow2，脱离文档流悬浮 |

- 玻璃仅在**这三个位置**启用（延续 R6「轻玻璃三处」原则，扩大为左栏/顶栏/浮层，右栏面板保持实色）。
- 照片观察区恒 `#08090B` 不变，玻璃不得覆盖观察区。

## 3. 关键修订项（相对 R6 v2）

1. **圆角上调一档**：卡片 12→16（`lgC`），窗口级容器 16，控件（按钮/输入框/chips）8（`mdC`）；pill 用在分类 chips 与开关。滑块轨道改 macOS 式：**轨道 6px 圆头、已完成段 accent、球体白色带 0.5px hairline 描边 + shadow1**。
2. **hairline 分隔**：面板内部一律 1px `line` 色 hairline，替代整块卡片边框；卡片本身不再描边，靠背景色差 + 间距分层。
3. **顶栏**：44px 保持；玻璃材质；左侧可加窗口控制区留白；工具按钮 hover 用 `accent 8%` 圆角方块（8px 圆角）。
4. **开关/复选**：改 macOS 式——开关 40×22 圆头（ON 时 accent）；复选 16px 圆角 5px。
5. **字体**：中文界面主字体栈首位加 `"PingFang SC", "Microsoft YaHei UI"`；数字/参数仍 JetBrains Mono。字号体系不变。
6. **动效**：全部 transition 200ms ease-out；面板展开 240ms cubic-bezier(0.2,0.8,0.2,1)；窗口级浮层出现带 4px 上移淡入。
7. **色彩**：令牌不动。macOS 质感靠材质与阴影表达，**不引入新彩色**；accent（muted gold）使用占比仍 ≤2%。

## 4. 落地顺序

- 批次 M-1（先做）：tokens.css 增 `blur-glass` 组合类（backdrop-filter 全家桶）+ 开关/复选控件组件化 + 滑块改型 → 影响全局。
- 批次 M-2：LeftRail / 顶栏 / 二级导航换玻璃；hairline 化右栏。
- 批次 M-3：浮层（筛选浮层、下拉、模态）统一 M2 材质 + 动效。
- 现有五件事收口（红条摘要/裁定文档/HistoryPanel 标题）**不受影响，先做完再进 M 批次**。

## 5. 验收

- 深浅双主题下玻璃可读性检查（浅色主题玻璃底 = `rgba(255,255,255,.75)`，文字对比 ≥ 4.5:1）。
- 观察区无玻璃；无新增硬编码色（backdrop-filter/阴影走令牌或组合类）。
- 基线重抓后 develop / library 双模式截图给用户评审。
