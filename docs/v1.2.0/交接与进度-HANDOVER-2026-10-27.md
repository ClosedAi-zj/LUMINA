```bash
cmake --build build/engine
ctest --test-dir build/engine --output-on-failure
```
- `cmake`/`ninja` **不在默认 PATH**，必须显式 export（上表路径来自 `build/engine/CMakeCache.txt`）。
- 源码根是 `engine/`（自带 CMakeLists.txt），产物 `build/engine/lumina-engine.exe`。
- 官方构建脚本：`D:/LUMINA/scripts/build-engine.ps1`（内部 source `scripts/env.ps1`）。

### 4.2 ⚠️ `libraw.a` 坑（会直接让 cmake 配置失败）
`thirdparty/libraw/lib/` 被 `.gitignore:15` 忽略，**worktree 里没有预编译库**。每次新建 worktree 必须：
```bash
mkdir -p <worktree>/thirdparty/libraw/lib
cp /d/LUMINA/thirdparty/libraw/lib/libraw.a <worktree>/thirdparty/libraw/lib/
```
报错形态：`CMake Error at CMakeLists.txt:18 (message): missing libraw.a under ...`

### 4.3 worktree 规约
```bash
cd /d/LUMINA
git worktree add --no-checkout D:/LUMINA/build/<name> <commit>
cd <worktree> && git checkout <commit> -- engine thirdparty
```
- **只检出 `engine thirdparty`**：全量 checkout 会被安全规则拦（受保护文件名 `docs/架构设计-*.md`、`app/使用说明.txt`）。
- 已被占用的 worktree 路径：`build/qa-8997580`(8997580)、`build/qa-899`(8997580)、`build/qa-t24`(671af48)、`build/wt-fix-eng`(6c6224f)、`D:/LUMINA-verify`(e881dbb)。
- **worktree 目录删除会被安全规则拦截**（含受保护文件），无法 `rm -rf`；新建时用新路径名。

### 4.4 autocrlf 假 diff
Windows 下 `core.autocrlf=true`，脚本批量改文件会产生**全文件行尾假 diff**。改完必须 `git diff --numstat` 核对只有预期行；必要时 `git -c core.autocrlf=false` 恢复 blob。已咬人两次（kou-eng 两批 UI 提交各 659 行噪音）。
