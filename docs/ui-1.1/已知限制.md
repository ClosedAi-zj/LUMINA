# 已知限制（v1.1.0 RC · UI 侧）

> 只列"当前版本真实存在、且用户可感知"的限制；每条都带界面上的显式提示位置。
> 协议/引擎侧缺口另见 `docs/ui-1.1/水印与画廊协议缺口清单.md`（含字段设计稿，待评审排期）。

## ① 修图台蒙版渲染槽位上限 6

- **现象**：修图台预览最多渲染 6 个启用蒙版；第 7 个及以后的启用蒙版**不参与预览渲染**（参数仍会写入 XMP，导出管线的蒙版处理以引擎实现为准）。
- **原因**：预览着色器（GLSL ES 1.0）的蒙版槽位是常量展开的（`shaders.ts` applyMask0..5），不能动态扩容。
- **用户可见提示**：修图台 → 蒙版面板，启用蒙版超过 6 个时显示「渲染槽位上限 6：当前 N 个启用蒙版，超出部分（列表尾部）不参与预览渲染」。
- **缓解**：合并蒙版 / 关闭不用的蒙版（被关闭的蒙版不占槽位）。

## ② 文字水印仅支持 ASCII

- **现象**：导出文字水印由引擎内置 3×5 点阵渲染，只收录 ASCII（A–Z、0–9 与常用符号）；中文及其他非 ASCII 字符导出时显示为「?」。
- **用户可见提示**：导出 → 水印，输入框下的琥珀色提示「引擎点阵仅支持 ASCII：N 个字符导出时将显示为 ?」；所见即所得预览与导出结果一致（预览同样显示 ?，不假装支持）。
- **绕行**：水印文字用英文/数字/上表内符号；需要中文水印等待引擎字体渲染能力（缺口清单 W1）。

## ③（顺带记录）导出格式当前仅 JPG / TIFF

- 引擎 v1.0.0 的 `export.createJob` 仅支持 `jpg` / `tiff`；PNG / PSD（带图层）提交会报「导出格式暂不可用」。
- 用户可见提示：导出页格式选择器只放出 JPG / TIFF，旁注「PNG / PSD · 带图层：引擎 v1.0.0 暂不支持」。
