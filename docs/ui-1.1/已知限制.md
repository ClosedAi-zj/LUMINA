# 已知限制（v1.2.3 · UI 侧）

> 只列"当前版本真实存在、且用户可感知"的限制；每条都带界面上的显式提示位置。
> 协议/引擎侧缺口另见 `docs/ui-1.1/水印与画廊协议缺口清单.md`（含字段设计稿，待评审排期）。

## ① 修图台蒙版渲染槽位上限 32

- **现象**：修图台预览最多渲染 32 个蒙版；第 33 个及以后的蒙版**不参与预览渲染**（参数仍会完整写入 XMP，导出管线的蒙版处理以引擎实现为准）。
- **原因**：预览的蒙版传递走 4×8 图集（`maskField.ts` MAX_MASK_SLOTS = 32）+ 数据纹理定行数，与 GPU 侧槽容量绑定，不能动态扩容。v1.1 的 6 槽常量展开着色器已由 32 槽 mask pass 取代。
- **用户可见提示**：修图台 → 蒙版面板，超过 20 个时显示性能提示；达到 32 个时显示「已达蒙版渲染槽上限 32 个：新建按钮已停用…」，并禁用新建按钮。
- **缓解**：合并蒙版 / 关闭或删除不用的蒙版。

## ② 文字水印仅支持 ASCII

- **现象**：导出文字水印由引擎内置 3×5 点阵渲染，只收录 ASCII（A–Z、0–9 与常用符号）；中文及其他非 ASCII 字符导出时显示为「?」。
- **用户可见提示**：导出 → 水印，输入框下的琥珀色提示「引擎点阵仅支持 ASCII：N 个字符导出时将显示为 ?」；所见即所得预览与导出结果一致（预览同样显示 ?，不假装支持）。
- **绕行**：水印文字用英文/数字/上表内符号；需要中文水印等待引擎字体渲染能力（缺口清单 W1）。

## ③（v1.2.3 现状）导出格式四档已全部可用，剩余限制在 PSD 分层深度

- JPG / TIFF / PNG / PSD 四档均已由引擎 `export.createJob` 落地（v1.2.0 起 PSD 带图层、v1.2.1 起 PNG 内嵌 iCCP），导出页四个格式都可选，**不再有「PNG / PSD 暂不支持」的提示**。
- 当前真实限制：PSD 分层导出在**编辑节点数 > 20** 时降级为单层合成（背景 + 合成图），并在导出任务的 warnings 里明确回报「节点数 N > 20，PSD 降级为单层合成（超分层上限）」，不静默降级。
- 另：单个节点前缀渲染失败同样降级为单层合成并回报具体节点名（如「节点前缀渲染失败（xxx），PSD 降级为单层合成: …」）。
