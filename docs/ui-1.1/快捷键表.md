## 状态标记口径（重要）

- **✅ 实测**：冒烟脚本发握手行 → 主进程 `webContents.sendInputEvent` 把按键真正投进渲染层 → 脚本读 store / DOM 断言效果。走的是原生 keydown 链路，不是在代码里找 handler。
- **◻ 代码路径确认（未实测）**：handler 存在且逻辑读过，但没有被真实按键驱动过。**不标 ✅。**

## 说明

- 面板折叠（修图台顶栏「左栏 / 右栏」按钮）状态记忆在本机 `localStorage`（WP-B7）。
- 复制/粘贴的设置剪贴板是会话级内存（LR 语义），不跨应用、不落盘。
- 本轮 ✅ 的 8 个修图台按键由 `smoke.ts` 的 `keys-*` 握手段 + `electron/main.ts` 的 `KEY_INJECTION_STEPS` 表驱动，可重复执行：`cd app && LUMINA_SMOKE=1 npx electron .`，看 `workflow:` 一行。
- 精选 / 图库两节的按键尚未纳入回放（那两页的键位在进入页面时挂载，需要独立握手段）。标 ◻ 而非 ✅，就是"没验过"的意思。
